# Trafik Işığında Kırmızıya Kızgınlık Ölçeri

> **Resmî duyuru:** Bu yazılım, kırmızı ışıkta beklerken içinizde biriken kızginlığı *KKBB* (Kırmızıya Kızgınlık Birimi) cinsinden ölçer. Bilimsel değildir. Daha kötüsü: bilimsel olmadığının farkındadır.

## Bu proje neden var?

Çünkü yeşil yanana kadar direksiyonu ısırmamak bir medeniyet meselesidir.  
Bu kod, o medeniyeti milimetrik olarak takip eder. Takip ederken de sizi hafif hafif yargılar.

## Kurulum

```bash
python3 kizginlik.py
```

Bağımlılık yoktur. Sadece Python 3 ve biraz öz eleştiri yeter.

## Kullanım

Program size sorar:
- Kaç saniyedir kırmızıdasın?
- Klakson çaldın mı?
- Yan şeritteki adamın varoluşunu kişisel algıladın mı?

Sonra size resmi bir rapor basar. Raporun altında damga vardır. Damga şakadır. Damga ciddidir.

## KKBB Skalası

| Puan | Teşhis |
|------|--------|
| 0-10 | Zen bahçesi. Asansör müziği dinliyorsun.
| 11-30 | Hafif homurdanma. Anayasal hak.
| 31-60 | Direksiyon derisi tehdit altında.
| 61-90 | Klakson opera aryasına dönüştü.
| 91+ | Işık yanınca bile gidecek yerin kalmadı. Terapi önerilir, yazılım önerilmez.
